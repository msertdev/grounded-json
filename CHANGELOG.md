## [0.1.0] - 2026-09-06

### Added

- Deterministic field-evidence gate for JSON candidates
- Local, inert HTML and JSON-LD extraction
- Explicit CSS selector maps
- Zod SDK validation and portable safe JSON Schema subset
- Content-addressed source snapshots and receipt digests
- Offline receipt replay and script-free HTML inspector
- Local-only CLI with `demo`, `from-jsonld`, `verify`, and `inspect`
- Hostile-input, ambiguity, tampering, schema, extractor, renderer, and CLI tests
